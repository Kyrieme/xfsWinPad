更新日志

v0.12.0（2026-09-19）

  • 向量文件（.pat）静态检查新增三条规则，逐条取自 Chroma 3380 语言手册，并在手册全部示例 + 真实工程向量文件上回归，零误报： HEADER 声明的 pin 数与向量实际宽度不符（橙色警告）、 SPM_PATTERN 用 NORM / DBL 搭配 K_SET / Z_SET（红色错误，手册明文标注 compiler error）、RPT 重复次数超出 2 .. 16777215（橙色警告）。取舍一律「宁漏不误」—— 认不出的写法（如十六进制次数、残缺向量行）不报，宁可不报也不误报
  • 主题配色定义加固：两套内建主题的 32 个颜色字段改为显式点名赋值 —— 此前按位置赋值，漏写或顺序写错会静默错位（曾导致浅色主题标签配色整体偏移）； 现在写错顺序 / 重复字段直接编译报错，并加了全字段 × 双主题的护栏测试
  • 打包脚本的 VC 运行库查找增加兜底路径，新版 Visual Studio 下不再找不到依赖

提示仍标注「xfsWinPad 静态检查，非 CRAFT 编译结果」—— 静态检查用于提前发现问题，不替代厂商编译器。

v0.11.0（2026-09-18）

  • 跨文件静态检查：新增规则 —— .pln / .pat 引用的 .dec 里声明了 DEC_MODE APAS 时，本文件中的 IMATCH 向量微指令失效（仅支持普通模式向量），违规处给橙色警告波浪线。 三重确认才报警：.dec 真的能在磁盘上找到、APAS 声明无歧义、 IMATCH 完整词匹配 —— 找不到 .dec 时静默，零误报纪律不变
  • 跨文件自动补全：被引用 .dec 定义的引脚名 / 引脚组 / 时序名自动进入 .pln / .pat 的词汇补全 —— 输入前缀即可补全 .dec 里定义的名字，不用翻回定义文件查询
  • 补全符号随文档保存自动刷新，且与「静态检查」开关独立 —— 关闭检查不影响跨文件补全
